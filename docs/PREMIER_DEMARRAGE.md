# Premier démarrage

Au premier lancement, CONSTANT demande de créer un mot de passe local de huit
caractères minimum, puis de le confirmer. Ce secret protège l'accès à
l'interface sur cet appareil; il n'est pas transmis à Instagram ni à un serveur.

À chaque nouvelle session, CONSTANT affiche sa bannière, demande le mot de passe
masqué et limite l'accès à trois essais. Après authentification, le tableau
récapitulatif indique le nombre de profils locaux, le profil sélectionné, le
nombre de liens et l'état de la connexion.

Le menu accepte les numéros affichés. Les saisies inconnues sont refusées sans
quitter le programme. `[00]` ferme la session. `Ctrl+C` interrompt proprement
l'application.

Pour désactiver l'animation au lancement, choisis `[12] Paramètres`. Le mode
`CONSTANT_NO_ANIMATIONS=1` permet aussi de désactiver l'animation pour un seul
lancement.

Le mode de démonstration est local. Le mot de passe choisi n'est pas une licence
à durée limitée ou validée par un serveur.
